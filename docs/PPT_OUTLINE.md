# CNS Security Lab - PPT Outline

This outline is designed for a 6-student presentation during the Innovative Exam.

## Slide 1: Title Slide
- **Title:** CNS Security Lab: An Interactive Learning & Quiz Platform
- **Subtitle:** Innovative Exam Presentation
- **Team:** [List all 6 student names]
- **Visual:** Project logo or screenshot of the Dashboard.

## Slide 2: The Problem
- **Speaker:** Student 1
- **Content:** 
  - Network security concepts (encryption math, firewall rules) are abstract and hard to visualize.
  - Traditional studying involves reading slides, which leads to poor retention.
  - Need a way to demonstrate concepts live and test knowledge immediately.

## Slide 3: Our Solution
- **Speaker:** Student 1
- **Content:** 
  - A unified web application combining **Theory (Learn)**, **Practice (Playgrounds)**, and **Evaluation (Quiz)**.
  - Covers 8 core modules: Crypto, Auth, Firewalls, Cloud, Attacks, IDS, TLS, AI.
  - 100% serverless, runs instantly in the browser.

## Slide 4: Architecture & Tech Stack
- **Speaker:** Student 2
- **Content:** 
  - **Frontend:** Next.js 16, React 19, Tailwind CSS.
  - **Simulators:** Pure TypeScript algorithms (No real backend required).
  - **State:** Zustand (for Quiz Engine and timers).
- **Visual:** Simple architecture diagram (React -> TypeScript Libs -> User Browser).

## Slide 5: Cryptography & Auth Modules
- **Speaker:** Student 3
- **Content:** 
  - Brief overview of RSA math (using BigInt in JS).
  - Demonstration of Password Entropy and TOTP (Google Authenticator) simulators.

## Slide 6: Network Defense (Firewalls & IDS)
- **Speaker:** Student 4
- **Content:** 
  - Difference between Stateless (ACLs) and Stateful Firewalls.
  - How our IDS simulator catches SQLi payloads using Signature-based detection.

## Slide 7: Modern Threats (Cloud, Attacks, AI)
- **Speaker:** Student 5
- **Content:** 
  - Shared Responsibility Model in Cloud (AWS/Azure).
  - Simulating Prompt Injection (Jailbreaks) in Large Language Models.

## Slide 8: The Quiz Engine & Revision Hub
- **Speaker:** Student 6
- **Content:** 
  - Built-in Quiz with Rapid-Fire and Scenario-based rounds.
  - Master Complexity Table and Flashcards for Viva prep.
- **Action:** Transition to Live Demo.

## Slide 9: Live Demo
- **Speaker:** Team
- **Content:** 
  - Walkthrough of the application (localhost:3000).
  - Run a quick 3-question quiz round with the audience/teacher.

## Slide 10: Conclusion & Q&A
- **Content:** 
  - Summary of what we learned (Next.js, TS algorithms, Security concepts).
  - Thank you & Questions.
